## 🎯 Hook Capabilities

### useAuth()
```typescript
{
  isAuthenticated: boolean
  isLoading: boolean
  user: QuelixUser | null
  session: QuelixSession | null
  error: string | null
  signIn: (input: SignInInput) => Promise<void>
  signUp: (input: SignUpInput) => Promise<void>
  signOut: () => Promise<void>
  refresh: () => Promise<void>
}
```
- Manages complete auth lifecycle
- Auto-stores tokens in localStorage
- Integrates with QuelixClient and context
- Handles token refresh

### useUser()
```typescript
{
  user: QuelixUser | null
  isLoading: boolean
  error: string | null
  updateUser: (input: UpdateUserInput) => Promise<QuelixUser>
  deleteAccount: (password: string) => Promise<void>
}
```
- Updates user profile
- Deletes account with password verification
- Auto-syncs with auth context

### useSignIn / useSignUp / useSignOut
- Simplified wrappers around useAuth
- Optimized for form components
- Minimal API surface

### useEmailVerification / usePasswordReset
- Complete verification/reset flows
- Track status with isSent/isVerified states
- Two-step recovery processes
